# RSNA Anonymizer — feature overview video

Remotion Studio project that walks through the main product features from the clinician manual.

```bash
cd remotion-features
npm install
npm run dev
```

Open [http://localhost:3000/FeaturesOverview](http://localhost:3000/FeaturesOverview).

Composition `FeaturesOverview` (~21s, 1920×1080, 30fps):

1. Opening
2. De-identify DICOM tags on import
3. Search / import from folder or PACS
4. View Dataset and Series View
5. Process AI tools (Embedded PHI, Harmonize, Face blur, Batch)
6. Send anonymized studies
7. Desktop GUI or headless modes
8. Closing
