## 1. Detectors compared

| Detector id | What it uses | What it does not use |
| --- | --- | --- |
| `patterns` | Locale regex / cue rules for dates, addresses, MRN/SSN, phone, email; titled/labeled name cues | spaCy; Presidio; neural models |
| `spacy_ner` | spaCy `en_core_web_sm` entities: PERSON→NAME, GPE/LOC/FAC→LOCATION, DATE→DATE | Regex / cue pack |
| `presidio_transformers` | Presidio English predefined recognizers (including DATE_TIME, phone, email) + spaCy NER + locale MRN/SSN patterns; DICOM UID tags not scanned; UID-shaped spans dropped | Neural clinical DeID models (e.g. OBI) |

Each detector was scored alone (no score mixing across detectors).

## 2. Metrics

Span match: same label and overlapping character offsets.

| Symbol | Definition |
| --- | --- |
| TP | Predicted span matches a gold span |
| FP | Predicted span with no matching gold span |
| FN | Gold span with no matching prediction |
| P (precision) | TP / (TP + FP); 0 if no predictions |
| R (recall) | TP / (TP + FN); 0 if no gold |
| F1 | 2PR / (P + R); 0 if P = R = 0 |

**False-alarm corpora** have no gold PHI spans. Reported:

| Symbol | Definition |
| --- | --- |
| N | Documents scored |
| docs≥1 | Documents with ≥1 predicted PHI span (any scored label) |
| rate | docs≥1 / N |
| span counts | Total predicted spans by label |

An F1 cell of `—` means that label has **no gold spans** in that set (metric undefined / not applicable), not that the detector scored zero.

## 7. Conclusions supported by the numbers

1. **Unlabeled mid-report NAME:** `patterns` recall = 0 (0/480 ReXErr, 0/300 Open-i). `spacy_ner` and `presidio_transformers` have identical NAME scores on sets A and B (ReXErr F1 = 0.636; Open-i F1 = 0.747).
2. **Unlabeled mid-report DATE:** `patterns` and `presidio_transformers` reach F1 = 1.000 on A and B; `spacy_ner` DATE recall = 0.500 on both (misses half of inserted dates).
3. **Identifier / phone / email formats (set D):** `patterns` and `presidio_transformers` F1 = 1.000; `spacy_ner` F1 = 0.000 (no ID/phone/email recognizers).
4. **False alarms on clean report text (FA1/FA2):** `patterns` rate = 0; spaCy and Presidio rate = 0.184 (ReXErr) and 0.029 (Open-i), driven by NAME.
5. **Presidio vs spaCy on NAME:** no NAME F1 difference on A/B; Presidio differs by adding pattern-based DATE/ID/phone/email coverage. Presidio does not reduce NAME false alarms relative to spaCy on FA1/FA2.

---

## 8. Implication for the next design step

Any candidate that relies on general-domain PERSON tagging (spaCy / current Presidio path) buys mid-report NAME recall at the cost of an 18.4% document-level false-alarm rate on the ReXErr sample used here. A pattern-only system avoids those false alarms but detects 0 unlabeled mid-report names. The open problem is improving NAME recall above 0 without reproducing the FA1 NAME false-alarm rate of spaCy/Presidio.
