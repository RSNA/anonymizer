# Anonymizer scripts

| Script | Role |
| --- | --- |
| `default-anonymizer.script` | Packaged base script; project scripts are compiled from this plus the selected de-identification options |

Edit the project script via Settings (or import a custom CTP script). Private tags are not in this script; Retain Safe Private uses the TCIA Private Tag KB under `assets/tcia_kb/`.

DATEINC for private-tag date ops: `controller/private_tags/dateinc.txt`.
