AI Batch Process

AI Batch Process runs one or more enabled AI Features on many studies at once from the Dataset view, instead of opening each series manually in Series View. It is useful after import when you want to harmonize descriptions, remove burnt-in text, or blur faces across an entire cohort.

Before you start

  1. Open a project and import the studies you want to process.
  2. On the Welcome screen, click AI Features and enable the tools you need (see AI Features).
  3. Complete downloads and the face license if using Face De-identify.
  4. Confirm each enabled tool shows a ready status.

Starting a batch run

  1. On the dashboard, open the Dataset view (patient/study list).
  2. Select one or more studies (or patients) using the same selection methods as for export.
  3. Click AI Batch Process.
  4. In the options dialog, check each algorithm you want to run:
    • Remove Burnt-in Annotation — choose black out or blend mode.
    • Harmonize — CT series descriptions only.
    • Face De-identify — head CT face blur.
  5. Click Start. A progress dialog shows the current study, series, and phase.

Order of operations

When you select multiple tools, the batch runner processes them in this order for each series:

  1. Remove Burnt-in Annotation (if selected)
  2. Harmonize (if selected)
  3. Face De-identify (if selected)

This order avoids re-reading pixels after they have been modified and keeps memory use predictable on large jobs.

What happens during processing

  • Each series is evaluated. If a tool does not apply (wrong modality, already done, not ready), it is skipped and noted in the log.
  • You can cancel between series; the current series may finish its active step before stopping.
  • A summary at the end lists completed, skipped, and failed items.
  • Detailed lines are written to the project log file for troubleshooting.

After batch completes

  • Spot-check representative series in Series View or Dataset projections.
  • Export anonymized data when satisfied (see Help/Operation).
  • Re-running batch on the same studies usually skips work already recorded in project metadata (for example pixel-PHI already scanned), unless you clear caches or force reprocessing.

Common messages

  • No AI features are enabled — on the Welcome screen, click AI Features and turn on at least one tool.
  • AI features are not ready — open AI Features from the Welcome screen and finish model downloads or license steps.
  • Skipped (not CT) — Harmonize or Face De-identify was selected but the series is another modality.
  • Skipped (already harmonized / already scanned) — previous batch or manual run recorded completion; safe to ignore unless you intentionally want to redo work.
