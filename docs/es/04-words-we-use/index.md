# Palabras que usamos

Glosario breve para clínicos. Cuando TI usa otros términos, suelen ser las mismas ideas.

| Palabra | Significado |
| --- | --- |
| **Estudio** | Una visita de examen (por ejemplo un CT de tórax). Puede contener varias series. |
| **Serie** | Un conjunto de imágenes relacionadas (por ejemplo cortes axiales finos, o un scout). |
| **Instancia / imagen** | Un único fotograma o archivo de corte. |
| **PHI** | Información sanitaria protegida — identificadores que podrían revelar quién es el paciente. |
| **Desidentificar / anonimizar** | Eliminar o sustituir identificadores para que el estudio sea más seguro de compartir para investigación. |
| **Texto quemado** | Palabras dibujadas en la propia imagen (no solo en las etiquetas del archivo). Frecuente en ecografía. |
| **Cuarentena** | Carpeta de retención para archivos que no se pudieron importar (tipo incorrecto, IDs faltantes, fallo de búsqueda, etc.). |
| **Conjunto de datos** | La lista en la aplicación de pacientes, estudios y series de su proyecto (antes llamado Índice PHI). |
| **Proyecto** | Un espacio de trabajo con nombre, con sus propios ajustes y carpeta de almacenamiento. |
| **Lista blanca (OCR)** | Etiquetas cortas permitidas (por ejemplo L/R) que **no** deben eliminarse al limpiar texto quemado. |

!!! note "Cuando hable con TI"
    Términos como **AE Title**, **SOP Class**, **transfer syntax** y **C-MOVE** describen cómo se comunican los sistemas. Solo suele necesitarlos al conectar con un archivo hospitalario—véase [Crear un proyecto → Cuando hable con TI](../05-create-project/#when-you-talk-to-it).
