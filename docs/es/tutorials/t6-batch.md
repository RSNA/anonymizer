# T6 — Procesar una lista de estudios

## Objetivo
Ejecutar el Procesamiento por lotes de IA desde el Conjunto de datos en varios estudios.

## Pasos
1. Seleccione estudios en el Conjunto de datos → Procesamiento por lotes de IA.
2. Elija algoritmos y opciones → Iniciar.
3. Lea el resumen; compruebe una muestra en Vista de Series.

En servidores sin GUI, use las mismas herramientas mediante [Ejecutar sin interfaz](../10-headless/).
