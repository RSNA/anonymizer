# T2 — Crear un proyecto e importar una carpeta

## Objetivo
Crear un proyecto e importar una carpeta de prueba para que los estudios aparezcan en el Conjunto de datos.

## Pasos
1. **Archivo → Nuevo Proyecto** y configure el almacenamiento.
2. Importe un directorio de archivos DICOM de prueba.
3. Abra **Conjunto de datos** y expanda un estudio.
