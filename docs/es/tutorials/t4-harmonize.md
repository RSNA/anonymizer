# T4 — Estandarizar nombres de series (Harmonize)

## Objetivo
Ejecutar Harmonize en una serie CT/MR (y opcionalmente XR/US planar) y aplicar la descripción sugerida.

## Pasos
1. Descargue los paquetes de Harmonize; configure la resolución CT/MR en Funciones de IA. Opcionalmente descargue parte del cuerpo XR / proyección de tórax XR para demos CXR.
2. Vista de Series → Armonizar descripción → revise **Evidencia** / **Fuente** del Playbook → Aplicar.
3. Pruebe `davidson_cxr` y `us_rgb_single_frame` para Harmonize planar (sin TotalSegmentator).
4. Cuando se aplica la última serie de un estudio, se establece automáticamente la mejor descripción de estudio LOINC; cámbiela desde el Conjunto de datos si hace falta.
