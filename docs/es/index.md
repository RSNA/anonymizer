# RSNA DICOM Anonymizer

Bienvenido al **manual de usuario clínico** del RSNA DICOM Anonymizer (V19).

Esta guía sigue el flujo de trabajo de escritorio en orden.

## Por dónde empezar

1. [Empezar aquí](01-start-here/) — qué hace el programa
2. [Instalación y primer inicio](02-install/) — poner la aplicación en marcha (pantalla Bienvenido)
3. [Configuración de Funciones de IA](03-ai-features-setup/) — descargar modelos desde Bienvenido (opcional pero recomendado)
4. [Palabras que usamos](04-words-we-use/) — glosario breve
5. [Crear un proyecto](05-create-project/) — almacenamiento + **Ajustes del Proyecto**
6. [Buscar](06-search/) — importar desde carpeta o PACS (Panel **Buscar**)
7. [Vista](07-view/) — Conjunto de datos, proyecciones y Vista de Series (Panel **Vista**)
8. [Procesar](08-process/) — Quitar texto quemado, Armonizar, Face blur, lotes
9. [Enviar](09-send/) — enviar estudios anonimizados (Panel **Enviar**)
10. [Ejecutar sin interfaz](10-headless/) — modos laboratorio/servidor
