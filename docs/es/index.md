# RSNA DICOM Anonymizer

Bienvenido al **manual de usuario clínico** del RSNA DICOM Anonymizer (V19).

Use las pestañas superiores: **Configuración** (capítulos 1–5), **Uso** (6–9), **Sin interfaz** (10) y **Referencia**.

**Configuración**

1. [Empezar aquí](01-start-here/index.md) — qué hace el programa
2. [Instalación y primer inicio](02-install/index.md) — poner la aplicación en marcha (pantalla Bienvenido)
3. [Configuración de Funciones de IA](03-ai-features-setup/index.md) — descargar modelos desde Bienvenido (opcional pero recomendado)
4. [Palabras que usamos](04-words-we-use/index.md) — glosario breve
5. [Crear un proyecto](05-create-project/index.md) — almacenamiento + **Ajustes del Proyecto**

**Uso**

6. [Buscar](06-search/index.md) — importar desde carpeta o PACS (Panel **Buscar**)
7. [Vista](07-view/index.md) — Conjunto de datos, proyecciones y Vista de Series (Panel **Vista**)
8. [Procesar](08-process/index.md) — Quitar texto quemado, Armonizar, Face blur, lotes
9. [Enviar](09-send/index.md) — enviar estudios anonimizados (Panel **Enviar**)

**Sin interfaz**

10. [Ejecutar sin interfaz](10-headless/index.md) — modos laboratorio/servidor
