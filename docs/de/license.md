# Lizenz

Der RSNA DICOM Anonymizer wird unter den im Projekt-Repository dokumentierten Bedingungen veröffentlicht (siehe LICENSE-Datei und [readme](https://github.com/RSNA/anonymizer)).

Drittanbieter-Bibliotheken (CustomTkinter, pydicom, EasyOCR, TotalSegmentator und andere) bleiben unter ihren eigenen Open-Source-Lizenzen (MIT, Apache 2.0, BSD, HPND und ähnliche). Gesichts- / Hirnstruktur-Funktionen können erfordern, während der [Einrichtung der KI-Funktionen](03-ai-features-setup) eine **akademische Lizenz** des Segmentierungsanbieters zu akzeptieren.
