# T5 — Gesicht auf einer Kopfuntersuchung unscharf machen

## Ziel
Gesichtsunschärfe auf einem Kopf-CT/MR vorschauen, QA bestätigen und speichern.

## Schritte
1. Akademische Lizenz akzeptieren und Gesichtsmodelle herunterladen.
2. Geeignete Serie öffnen → Gesichtsunschärfe-Vorschau.
3. Maskenabdeckung und QS BESTANDEN bestätigen → Speichern.
