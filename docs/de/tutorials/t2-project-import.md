# T2 — Projekt anlegen und Ordner importieren

## Ziel
Ein Projekt anlegen und einen Testordner importieren, sodass Studien im Datensatz erscheinen.

## Schritte
1. **Datei → Neues Projekt** und Speicher festlegen.
2. Ein Verzeichnis mit DICOM-Testdateien importieren.
3. **Datensatz** öffnen und eine Studie aufklappen.
