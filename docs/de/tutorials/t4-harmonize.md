# T4 — Seriennamen standardisieren (Harmonisieren)

## Ziel
Harmonisieren auf einer CT/MR-Serie (und optional planar XR/US) ausführen und die vorgeschlagene Beschreibung anwenden.

## Schritte
1. Harmonize-Pakete herunterladen; CT/MR-Auflösung unter KI-Funktionen setzen. Optional XR body part / XR chest view für CXR-Demos herunterladen.
2. Serienansicht → Beschreibung harmonisieren → Playbook-**Nachweis** / **Quelle** prüfen → Anwenden.
3. `davidson_cxr` und `us_rgb_single_frame` für planare Harmonisierung ausprobieren (kein TotalSegmentator).
4. Wenn die letzte Serie einer Studie angewendet ist, wird die beste LOINC-Studienbeschreibung automatisch gesetzt; bei Bedarf im Datensatz ändern.
