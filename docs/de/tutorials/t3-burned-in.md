# T3 — Eingebrannte Beschriftungen bereinigen

## Ziel
Eingebrannten Text auf einer Serie erkennen und entfernen, während L/R-Marker erhalten bleiben.

## Schritte
1. Sicherstellen, dass OCR-Modelle unter KI-Funktionen bereit sind.
2. Serienansicht öffnen → Text erkennen.
3. Grüne Rechtecke anklicken, um Behalter zu whitelisten → Text entfernen → Speichern.
