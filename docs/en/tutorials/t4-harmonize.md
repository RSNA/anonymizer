# T4 — Standardize CT/MR series names

## Goal
Run Harmonize on a CT or MR series and apply the suggested description.

## Steps
1. Download Harmonize packs; set CT/MR resolution in AI Features.
2. Series View → Harmonize Description → review → Apply.
3. If prompted for study description, choose or accept the LOINC match.
