# T4 — Standardize series names (Harmonize)

## Goal
Run Harmonize on a CT/MR series (and optionally planar XR/US) and apply the suggested description.

## Steps
1. Download Harmonize packs; set CT/MR resolution in AI Features. Optionally download XR body part / XR chest view for CXR demos.
2. Series View → Harmonize Description → review Playbook **Evidence** / **Source** → Apply.
3. Try `davidson_cxr` and `us_rgb_single_frame` for planar Harmonize (no TotalSegmentator).
4. When the last series in a study is applied, the best LOINC study description is set automatically; change it from Dataset if needed.
