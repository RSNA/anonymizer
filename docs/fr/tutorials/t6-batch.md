# T6 — Traiter une liste d’études

## Objectif
Lancer Traitement par lots IA depuis Jeu de données sur plusieurs études.

## Étapes
1. Sélectionnez des études dans Jeu de données → Traitement par lots IA.
2. Choisissez les algorithmes et options → démarrer.
3. Lisez le résumé ; contrôlez Vue des séries.

Pour les serveurs sans interface graphique, utilisez les mêmes outils via [Exécution sans interface](../10-headless/).
