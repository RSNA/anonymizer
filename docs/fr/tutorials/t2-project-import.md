# T2 — Créer un projet et importer un dossier

## Objectif
Créer un projet et importer un dossier de test pour que les études apparaissent dans Jeu de données.

## Étapes
1. **Fichier → Nouveau projet** et définir le stockage.
2. Importer un répertoire de fichiers DICOM de test.
3. Ouvrir **Jeu de données** et développer une étude.
