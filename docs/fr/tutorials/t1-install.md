# T1 — Installer et ouvrir l’application

## Objectif
Installer l’Anonymizer et atteindre l’écran Bienvenue avec les Fonctions IA disponibles.

## Étapes
1. Installez uv (`uv --version` pour confirmer), créez un venv Python 3.12 qui inclut tkinter, puis `uv pip install rsna-anonymizer` (19.0.1).
2. Sous macOS, `brew install libomp` avant d’utiliser les Fonctions IA.
3. Lancez `rsna-anonymizer` ; confirmez que Bienvenue s’ouvre ; ouvrez **Fonctions IA** et démarrez les téléchargements nécessaires.
