# T4 — Standardiser les noms de séries (Harmoniser)

## Objectif
Lancer Harmoniser sur une série CT/MR (et optionnellement XR/US planaire) et appliquer la description suggérée.

## Étapes
1. Téléchargez les packs Harmonize ; réglez la résolution CT/MR dans Fonctions IA. Optionnellement téléchargez région anatomique XR / vue thorax XR pour les démos CXR.
2. Vue des séries → Harmoniser la description → revoyez **Preuve** / **Source** Playbook → Appliquer.
3. Essayez `davidson_cxr` et `us_rgb_single_frame` pour Harmonize planaire (pas de TotalSegmentator).
4. Lorsque la dernière série d’une étude est appliquée, la meilleure description d’étude LOINC est définie automatiquement ; modifiez-la depuis Jeu de données si besoin.
