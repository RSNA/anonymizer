# T3 — Nettoyer les étiquettes incrustées

## Objectif
Détecter et supprimer le texte incrusté sur une série tout en conservant les marqueurs L/R.

## Étapes
1. Assurez-vous que les modèles OCR sont prêts dans Fonctions IA.
2. Ouvrez Vue des séries → Détecter le texte.
3. Cliquez sur les rectangles verts pour mettre en liste blanche les conservations → Supprimer le texte → Enregistrer.
