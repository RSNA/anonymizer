# Mots que nous utilisons

Glossaire court pour les cliniciens. Quand l’informatique utilise d’autres termes, ce sont en général les mêmes idées.

| Mot | Signification |
| --- | --- |
| **Étude** | Une visite d’examen (par exemple un CT thorax). Peut contenir plusieurs séries. |
| **Série** | Un ensemble d’images liées (par exemple des coupes axiales fines, ou un scout). |
| **Instance / image** | Un seul fichier de frame ou de coupe. |
| **PHI** | Protected health information — identifiants qui pourraient révéler qui est le patient. |
| **Désidentifier / anonymiser** | Supprimer ou remplacer les identifiants pour que l’étude soit plus sûre à partager pour la recherche. |
| **Texte incrusté** | Mots dessinés sur l’image elle-même (pas seulement dans les étiquettes du fichier). Fréquent en échographie. |
| **Quarantaine** | Dossier d’attente pour les fichiers qui n’ont pas pu être importés (mauvais type, identifiants manquants, échec de lookup, etc.). |
| **Jeu de données** | La liste dans l’application des patients, études et séries de votre projet (autrefois appelée PHI Index). |
| **Projet** | Un espace de travail nommé avec ses propres paramètres et son dossier de stockage. |
| **Liste blanche (OCR)** | Courtes étiquettes autorisées (par exemple L/R) qui ne doivent **pas** être supprimées lors du nettoyage du texte incrusté. |

!!! note "Quand vous parlez à l’informatique"
    Des termes comme **AE Title**, **SOP Class**, **transfer syntax** et **C-MOVE** décrivent comment les systèmes communiquent. Vous n’en avez en général besoin que pour la connexion à une archive hospitalière — voir [Créer un projet → Quand vous parlez à l’informatique](../05-create-project/#quand-vous-parlez-a-linformatique).
