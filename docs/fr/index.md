# RSNA DICOM Anonymizer

Bienvenue dans le **manuel utilisateur clinicien** du RSNA DICOM Anonymizer (V19).

Ce guide suit le flux de travail bureau dans l’ordre.

## Par où commencer

1. [Commencer ici](01-start-here/) — ce que fait le programme
2. [Installation et premier lancement](02-install/) — démarrer l’application (écran Bienvenue)
3. [Configuration des Fonctions IA](03-ai-features-setup/) — télécharger les modèles depuis Bienvenue (optionnel mais recommandé)
4. [Mots que nous utilisons](04-words-we-use/) — glossaire court
5. [Créer un projet](05-create-project/) — stockage + **Paramètres du projet**
6. [Rechercher](06-search/) — importer depuis un dossier ou un PACS (Tableau de bord **Rechercher**)
7. [Vue](07-view/) — Jeu de données, projections et Vue des séries (Tableau de bord **Vue**)
8. [Traiter](08-process/) — Supprimer le texte incrusté, Harmoniser, Face blur, lots
9. [Envoyer](09-send/) — envoyer des études anonymisées (Tableau de bord **Envoyer**)
10. [Exécution sans interface](10-headless/) — modes laboratoire/serveur
