# T1 script — Install and open the app (≈5 min)

1. Show terminal: install uv (`uv --version`), Python 3.12+tkinter venv, `uv pip install rsna-anonymizer` (19.0.1).
2. macOS: `brew install libomp` before AI Features.
3. Run `rsna-anonymizer`; Welcome appears. Click AI Features; point out Download buttons.
4. Close setup; remind AI Features is only on Welcome (close project to return).
